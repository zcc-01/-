# 接口文档（交易域）

- Base URL：`http://127.0.0.1:8000`
- 在线调试：`/docs`（Swagger UI）
- 统一响应：`{"code": 0, "message": "ok", "data": ...}`，分页为 `data = {items, total, page, size}`
- 鉴权：`Authorization: Bearer <access_token>`；标注「匿名可访问」的接口不要求登录
- 业务域：交易域（UC-06～UC-10），负责人 李××

## 错误码（交易域新增部分）

沿用公共基础层 `app/core/errors.py` 的错误码，交易域只新增语义、不新增编号：

| code | HTTP | 交易域典型场景 |
|---|---|---|
| 40001 | 422 | 参数不合法（数量 < 1、手机号格式错、评分越界） |
| 40101 | 401 | 未登录 / 令牌过期 |
| 40301 | 403 | 越权：非本产地农户上架、非买家支付、消费者发货 |
| 40401 | 404 | 商品不存在 / 已下架 / 订单不存在 |
| 40901 | 409 | 同批次同规格商品重复上架、重复评价 |
| 42201 | 422 | 库存不足、状态机不允许、支付失败、超过重试上限 |

## 1. 商品上架（UC-06）

`POST /api/products` · 角色：农户

```json
{
  "farm_id": "FRM...",
  "batch_id": "BAT...",
  "title": "临安山核桃 手剥原味 500g",
  "crop_name": "临安山核桃",
  "spec": "500g/袋",
  "unit": "袋",
  "price": 68.0,
  "stock": 120,
  "cert_badge": "产地认证",
  "description": "产地直供，当季采收"
}
```

`data`：

```json
{
  "product_id": "PRD...", "product_no": "SP-20251119-3F2A",
  "farm_id": "FRM...", "farm_name": "青禾家庭农场",
  "batch_id": "BAT...", "title": "临安山核桃 手剥原味 500g",
  "price": 68.0, "stock": 120, "sales": 0,
  "status": "on_shelf", "status_label": "在售",
  "cert_badge": "产地认证", "can_buy": true,
  "rating_avg": 0.0, "review_count": 0
}
```

规则：

- 只有产地所有者可上架；`batch_id` 必须是本产地的批次，否则 403；
- `(farm_id, batch_id, title, spec)` 唯一，重复上架返回 409；
- 创建后默认 `on_shelf`，下架用 `PATCH /api/products/{id}/status`。

`PATCH /api/products/{product_id}` · 角色：农户 —— 改标题 / 规格 / 单位 / 价格 / 库存 / 描述 / 认证标识。

`PATCH /api/products/{product_id}/status` · 角色：农户

```json
{"status": "off_shelf"}
```

## 2. 检索与筛选（UC-07）

`GET /api/products` · 匿名可访问

| 参数 | 说明 |
|---|---|
| `keyword` | 标题、品种模糊匹配 |
| `farm_id` / `province` | 按产地、省份过滤 |
| `min_price` / `max_price` | 价格区间（传反了自动交换） |
| `cert_only` | 仅看有产地认证标识的商品 |
| `in_stock_only` | 仅看有货 |
| `sort` | `newest`（默认）/ `sales_desc` / `price_asc` / `price_desc` |
| `mine` | 农户传 `true` 看自己产地的商品（含已下架） |
| `page` / `size` | 分页，`size` 上限 100 |

默认只返回 `on_shelf` 商品。响应每项含 `farm_name`、`province`、`rating_avg`、`review_count`、`can_buy`。

`GET /api/products/{product_id}` · 匿名可访问

在列表字段基础上增加：

```json
{
  "batch": {
    "batch_id": "BAT...", "batch_no": "PC-20251101-DEMO",
    "crop_name": "临安山核桃", "plot_no": "A-03",
    "harvest_date": "2026-09-05", "status": "qualified", "event_count": 5
  }
}
```

下架商品仅本产地农户可见，其他角色返回 404。

## 4. 下单（UC-08）

`POST /api/orders` · 角色：消费者

```json
{
  "items": [{"product_id": "PRD...", "quantity": 2}],
  "address": {"receiver": "李小明", "phone": "13800000004", "detail": "浙江省杭州市临安区清凉峰镇 1 号"},
  "remark": "工作日白天送"
}
```

`data`：

```json
{
  "orders": [
    {
      "order_id": "ORD...", "order_no": "ORD-20251119-56E1",
      "farm_id": "FRM...", "total_amount": 136.0, "freight": 0.0, "pay_amount": 136.0,
      "status": "pending", "status_label": "待支付",
      "address_snapshot": "李小明 138****0004 浙江省杭州市临安区清凉峰镇 1 号",
      "items": [{"product_id": "PRD...", "product_title": "...", "unit_price": 68.0, "quantity": 2, "subtotal": 136.0}],
      "can_pay": true, "can_cancel": true, "can_ship": false, "can_receive": false, "can_review": false
    }
  ],
  "total": 1
}
```

关键约定：

- **金额只由服务端计算**：按库中当前价 × 数量，加运费（满 99 元免运费，否则 8 元）。客户端传 `price`、`total_amount` 一律忽略；
- **跨产地拆单**：购物车含多个产地的商品时，按 `farm_id` 拆成多笔订单，同一事务内全成功或全回滚；
- **库存扣减**走条件更新，任一商品 `affected_rows = 0` 即整笔事务回滚，返回 422 并带上 `data.product_id` 与剩余库存；
- 下单后 30 分钟内未支付会在支付时惰性取消，并由后台任务每 60 秒兜底清理；
- 若商品绑定的批次溯源码已全部作废，下单返回 422「平台暂停该商品销售」（跨域契约，只读 `trace_code`）。

## 5. 支付（UC-08）

`POST /api/orders/{order_id}/pay` · 角色：消费者

```json
{"channel": "mockpay"}
```

`data`：

```json
{
  "order_id": "ORD...", "order_no": "ORD-20251119-56E1",
  "status": "paid", "status_label": "已支付",
  "payment_no": "PAY-20251119-8C41", "trade_no": "MP20251119155051 65B30D",
  "pay_amount": 136.0, "attempt_count": 1,
  "message": "支付成功"
}
```

行为约定：

- 支付调用在**数据库事务之外**执行，网关返回后再用短事务更新订单与流水；
- 已支付订单重复调用为幂等返回（`message = 订单已支付，无需重复支付`），不会产生第二条成功流水；
- 支付失败返回 422，失败原因写入 `payment.fail_reason` 并累加 `attempt_count`；累计 3 次即自动取消订单并释放库存；
- 并发重复点击由 `payment.order_id` 唯一索引兜底。

`POST /api/orders/{order_id}/cancel` · 买家或平台运营

```json
{"reason": "买家主动取消"}
```

仅 `pending` 可取消，取消后库存原路释放。

## 6. 订单查询

`GET /api/orders?scope=mine|sales&status=&page=1&size=20` · 需登录

- `scope=mine`：我买到的（买家视角）
- `scope=sales`：我卖出的（农户视角，按本人产地过滤；平台运营可看全量）

`GET /api/orders/{order_id}` · 买家、供货农户、平台运营/监管可查看。

## 7. 发货与确认收货（UC-09）

`POST /api/orders/{order_id}/ship` · 角色：农户（须为供货产地所有者）

```json
{"express_no": "SF7788123456"}
```

仅 `paid` 可发货，发货后状态转 `shipped` 并记录 `shipped_at`。

`POST /api/orders/{order_id}/receive` · 角色：消费者

仅 `shipped` 可确认收货，状态转 `received`，此后才允许评价。

---

## 8. 评价晒单（UC-10）

`POST /api/orders/{order_id}/reviews` · 角色：消费者

```json
{"product_id": "PRD...", "rating": 5, "content": "扫码能看到批次链路，核桃很新鲜"}
```

- 仅 `received` 状态可评价，未收货返回 422；
- 商品必须在该订单明细中；
- `(order_id, product_id)` 唯一，重复评价返回 409；
- 展示时买家名脱敏（`李**`）。

`GET /api/products/{product_id}/reviews?limit=20` · 匿名可访问

## 9. 运维接口

`POST /api/orders/admin/sweep-expired` · 角色：平台运营

手动触发超时订单清理（等价于后台每 60 秒执行一次的定时任务），返回 `{"cancelled": n}`。
