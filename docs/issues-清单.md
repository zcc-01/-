# GitHub Issue 清单（可直接建单）

> 用途：把开发过程留痕到 Issue，配合 PR 形成"需求 → 实现 → 验证"的闭环佐证。
> 建单方式：仓库 → Issues → New issue → 选「任务」模板，把下表标题与验收标准粘进去；
> 或安装 GitHub CLI 后批量创建（文末附命令）。
> 建议每个 Issue 只对应一个可独立验收的增量，完成后由 PR 里的 `Closes #编号` 自动关闭。

## 批量创建（可选）

安装 GitHub CLI（`winget install GitHub.cli`）并 `gh auth login` 后：

```bash
gh issue create --title "搭建项目骨架与分层结构" --label task \
  --body "验收：uvicorn app.main:app 可启动；/api/health 返回 up"
```

或在仓库页手动新建，按上表逐条粘贴即可。建议给 Issue 打标签：
`task` / `trace` / `trade` / `account` / `infra`，并按里程碑归组。
